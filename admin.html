⚙ অ্যাডমিন প্যানেল

পোস্টারের ওপর মাউস টেনে ছবি বসার জায়গা (লাল বক্স) আঁকুন।
পোস্টার না বদলালে এটা বাদ দিন।
সেভ করার জন্য ফাইল নামান:

(frame.png শুধু নতুন পোস্টার দিলে লাগবে)
  1. নামানো ফাইল(গুলো) GitHub repository-তে যান।
  2. Add file → Upload files চাপুন।
  3. ফাইল ড্র্যাগ করে দিন, আর Commit changes চাপুন।
  4. ১-২ মিনিট পর সাইট রিফ্রেশ দিলে নতুন ডিজাইন দেখা যাবে।
